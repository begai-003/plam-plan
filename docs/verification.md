## 確認した機能

- P-001〜P-005：キット登録、一覧のカード／リスト切替、詳細、基本情報編集、画像を含む削除、塗料台帳の保持。
- P-006・P-007・P-014・P-015：色プラの複数成形色、記号の正規化・一意性、同じ成形色の複数グループへの割り当て、固定IDを維持した成形色の名前変更、参照中の削除禁止。
- P-008・P-009・P-016・P-021：単色100%、混色70/30、70/40の保存拒否と入力保持、0.1%単位の検証、工程編集・削除・上下移動、削除済み商品の新規選択拒否。
- P-010・P-017：任意のパーツ番号、番号未指定の明示、工程直前のマスキング注意、グループ・工程との参照整合性。
- P-011〜P-013・P-018：瓶の固定ID・ラベル・残量、残量0%の瓶の数量算入、希釈済み本数、負数・小数の拒否、在庫判定、検索とAND絞り込み、塗料の論理削除・復元。
- P-019・P-020：Auth EmulatorのGoogle資格情報APIで本人を認証、別UIDを拒否、ログアウト後のデータ非表示、詳細ルートの保持。
- A-09・A-10：ブラウザの2画面で実際のFirestore更新競合を発生させ、古いrevisionによる保存を拒否し入力を保持。オフライン時の保存禁止、同じIDでの登録再試行を検証。
- A-11・A-14：保存失敗時の新画像削除、結果不明時の画像保持、旧画像削除失敗の記録・再試行、キット削除失敗時の `deleting` 保持をサービス契約テストで検証。
- A-12・A-13：ハッシュ形式の詳細URL再読み込み、360px幅でのはみ出しなし、未保存入力の確認キャンセル、Escapeキーによるモーダル終了と元のボタンへのフォーカス復帰。
- A-01：未認証・別UIDのFirestore取得／一覧／作成／更新／削除とStorage取得／一覧／アップロード／削除をすべて拒否。本人の操作、revision・createdAt・許可フィールド・型・画像の制約も検証。

## 未検証の範囲

- 実際のGoogleアカウントのポップアップ認証。このクラウドのChromiumは環境プロキシCAを信頼せず、TLS証明書エラーになりました。証明書ストアの変更は自動承認レビューで拒否され、利用者からも「変更せず、認証APIで検証する」と指定されたため、変更していません。TLS検証は無効化していません。ポップアップ処理自体はサービス契約テストで検証し、ブラウザの認証・データ操作は公式Auth Emulatorが受け付ける架空のGoogle資格情報で確認しました。
- 本番Firebaseへの接続、Rulesの本番配備、CORS・承認済みドメイン、実アカウントでの端末間同期。
- GitHub Pagesへの公開、公開URL上の再読み込み、GitHub Actionsの実行。
- Windows／macOS／iOS／AndroidおよびEdge／Firefox／Safari実機。

これらは公開時に確認し、実際のOS・ブラウザ・日付を追記してください。テスト用の認証ヘルパーは本番ビルドの依存グラフに含めません。`TEST_OAUTH_POPUP=true npm run test:e2e` は実際のGoogleポップアップをAuth Emulatorで検証する追加チェックとして残しています。
